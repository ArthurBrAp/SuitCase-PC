## 📌 Sobre o projeto

O **SuitCase PC** é um computador montado dentro de uma mala. Usamos o espaço interno para acomodar as principais peças (placa-mãe, memória RAM, fonte de alimentação e HD) junto com uma tela integrada, criando um PC de verdade em um formato diferente e fácil de transportar.

## 🖥️ Configuração

| Componente | Especificação |
|---|---|
| Processador | Intel Core i3-550 |
| Memória RAM | 6 GB |
| Armazenamento | HD de 500 GB |
| Sistema operacional | Windows 10 Pro |

Detalhes completos em [`especificacoes.md`](especificacoes.md).

## 🔧 Destaques da montagem

- **Tela integrada** no interior da mala, conectada via HDMI
- **Furos de ventilação** na estrutura da mala para saída do ar quente
- **Portátil**: o computador inteiro vai junto com a mala
